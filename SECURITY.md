# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in this project, please report it by emailing [arunneupane0000@gmail.com](mailto:arunneupane0000@gmail.com).

Please do not create a public GitHub issue for security-related concerns.

## Response timeline

- Acknowledgment of your report within 48 hours
- A detailed response within 5 business days
- Fix released as soon as possible depending on severity

## Scope

This is a personal learning project. Security issues in dependencies should be reported to their respective maintainers.
