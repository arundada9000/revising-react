# Contributing

Thank you for your interest in this React learning repository. This is a personal study project where I document my journey learning React.js.

## How to contribute

- Fork the repository
- Create a feature branch (`git checkout -b feature/your-idea`)
- Commit your changes using conventional commit messages
- Push to your branch (`git push origin feature/your-idea`)
- Open a Pull Request

## Commit conventions

This project uses conventional commits:

- `feat:` - new React concepts or examples
- `docs:` - documentation changes
- `chore:` - configuration or setup changes
- `fix:` - bug fixes
- `refactor:` - code restructuring without behavior changes
- `test:` - adding or updating tests

## Code style

- Keep examples simple, self-contained, and focused on a single concept.
- Follow the existing folder structure when adding new files.
- Do not add commented-out code.
- Use meaningful variable and function names.

## Reporting issues

If you find a bug or have a suggestion, please open an issue describing the problem or improvement in detail.
